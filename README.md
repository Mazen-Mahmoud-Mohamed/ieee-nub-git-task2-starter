# IEEE NUB Git Lab — Task 2 Starter

**GitHub Collaboration & Advanced Git**  
IEEE NUB Student Branch · Smart Plant Monitor practice project

> **Instructor preparation — not yet released for grading.**

This public repository is the shared starting point for Task 2. Every student will work on a **personal fork**. Do not change this instructor-owned repository.

## Project

The example Arduino sketch `sensor.ino` reads a simulated soil-moisture input on `A0` and indicates dry soil using a buzzer on pin `8`. The code is educational and has not been tested on physical hardware.

The starter contains two intentionally divergent branches:
- `main`
- `feature/lcd-display`

They will require an intentional merge-conflict resolution during the exercise. **When forking, uncheck "Copy the DEFAULT branch only"** to bring both branches.

## What to study

Merge conflicts · `.gitignore` · tracked-file removal · stash · remotes · push/pull/clone · fork · pull requests · review · issues · README.

See [Task 2 starter guide](docs/TASK2_STARTER_GUIDE.md) for the scenario and safe-work instructions.

## Safety

- Never put real `.env` files, passwords, tokens or personal data in this public repository.
- `local-settings.txt` contains **dummy** values to practice stopping the tracking of an existing file.
- Open practice Issues and Pull Requests in **your own fork** unless your instructor says otherwise.
